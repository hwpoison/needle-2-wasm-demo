# Needle 2 WASM implementation

## What is this
This is a simple html demo file to execute tool calling using the agentic model Needle 2.

Project site: https://cactuscompute.com/needle

### How to run it
- Download the needle.wasm, needle2.cact and needle.js binaries from https://huggingface.co/Cactus-Compute/needle2/tree/main/wasm and put inside the index.html folder.
- Run a server using `python -m http.server 8000` then go to `127.0.0.1:8000`
